# 决策内核：意图路由小模型与三层决策链路

> 版本：V1.2.1 ｜ 运行环境：纯 CPU、本地离线可推理 ｜ 适用链路：团队群聊（可插拔扩展至单聊、圆桌）

## 1. 背景与定位

平台原有决策全部由「正则关键词规则 + 云端大模型提示词」完成，本地没有可训练、可量化评测的决策模块。本次补齐一个**轻量、可训练、可评测、可演示**的意图路由决策内核：

- 把用户诉求自动归入封闭标签空间，并决定本轮回复是否携带本地产物（文档 / 表格 / 配图）；
- 采用「小模型达标 → 规则兜底 → 大模型仲裁上游」的三层链路，任何一层失效都不阻断对话；
- 每一次决策的标签、置信度、命中层级、耗时全部留痕，前端提供可解释面板。

## 2. 三层决策链路

```
用户诉求 text
   │
   ├─ 第 1 层：本地 ML 分类器（TF-IDF + 朴素贝叶斯）
   │      ├─ 置信度 ≥ 阈值（0.6）→ 采纳模型标签（layer = model）
   │      └─ 置信度 < 阈值     → 转入第 2 层
   │
   ├─ 第 2 层：确定性关键词规则基线（layer = rule）
   │      └─ 模型缺失 / 损坏 / 推理异常时，直接由本层兜底
   │
   └─ 第 3 层：上游大模型仲裁（既有 LLM 链路，不在本地模型范围内）
```

设计要点：

- **永不抛异常**：模型文件缺失、损坏或推理出错时，路由静默降级到规则层，保证聊天流程可用；
- **置信度门槛**：模型低置信度不强行决策，交给更可控的规则层；
- **可插拔**：分类器接口固定为 `predict(text) -> 决策结果`，后续可替换为逻辑回归、小蒸馏模型而不改动上层业务。

## 3. 标签体系与产物动作

| 标签 | 含义 | 回复产物 |
| --- | --- | --- |
| `chat` | 闲聊 / 通用问答 | 无（纯文本） |
| `doc` | 文档 / 报告 / 方案 / 总结 / 讲稿 | `docx` 文件 |
| `sheet` | 表格 / 清单 / 对比表 / 统计表 | `csv` 文件 |
| `image` | 配图 / 示意图 / 流程图 / 思维导图 | `png` 图片 |
| `vision` | 理解上传图片（读图 / 识别图中内容） | 无（走多模态） |
| `risk` | 敏感 / 不安全诉求 | 无（风险拦截） |

规则基线按「风险 → 图片理解 → 配图 → 表格 → 文档 → 闲聊」的优先级匹配关键词，更具体的标签先命中。

## 4. 模型选型与训练

### 4.1 方案

- **特征**：`TfidfVectorizer`，字符级滑窗（`char_wb`），2–4 元字符 n-gram，适配中文短诉求、不依赖分词词典；
- **分类器**：`MultinomialNB`（alpha = 0.1），多项式朴素贝叶斯，文本分类轻量稳定；
- **流水线**：`Pipeline(特征提取 → 分类器)`，训练后用 `joblib` 整体落盘；
- **推理**：模块级单例懒加载，进程内只加载一次。

### 4.2 为什么不选深度学习 / LoRA

备赛周期与算力受限（纯 CPU、四天），历史日志样本量很少。深度模型 / 大模型 LoRA 在小样本下容易过拟合、训练与部署成本高、现场离线不可控。朴素贝叶斯 + TF-IDF 在短文本意图分类上性价比高、毫秒级推理、权重可随包离线分发；后续样本积累后可平滑替换为更强的分类器。

## 5. 数据集

- 种子样本：**90 条**手写模板句式，覆盖六类标签；
- 划分：训练集 **72** 条 / 验证集 **18** 条（固定随机种子 42，可复现）；
- 落盘：`data/intent_dataset.csv`（`text,label` 两列），后续可直接接入真实标注样本扩充；
- 模型权重：`models/intent_router.joblib`。

> 说明：当前种子集规模偏小，部分类别在验证集中样本为 0，离线指标仅供链路对比参考；扩充标注样本后指标会进一步稳定。

## 6. 离线评测结果

在验证集（18 条）上对比「三层链路（模型 + 规则兜底）」与「纯规则基线」：

| 决策链路 | 准确率 Accuracy | 宏 F1 |
| --- | --- | --- |
| 三层链路（小模型 + 规则兜底） | **0.8333** | **0.6983** |
| 纯规则基线 | 0.7778 | 0.6611 |

- 三层链路相对规则基线：准确率 +5.55 个百分点，宏 F1 +0.0372；
- 本地推理平均耗时：**毫秒级**（约 1.2–3.4 ms / 条，不含网络调用）；
- 评测脚本：`python -m app.decision.evaluate`，可在扩充数据集后复跑。

## 7. 可解释性与审计留痕

### 7.1 决策记录落库

每次路由决策写入 `decision_logs` 表：

| 字段 | 说明 |
| --- | --- |
| `scope` | 链路场景（team / chat / forum） |
| `reference_id` | 关联会话 / 团队 ID |
| `user_id` / `persona_id` | 发起用户 / 发言智能体 |
| `text` | 原始诉求（截断 500 字） |
| `label` | 命中标签 |
| `confidence` | 置信度（0–1） |
| `layer` | 决策层级：`model` / `rule` |
| `keyword` | 规则层命中的关键词（模型层为空） |
| `elapsed_ms` | 本条决策耗时（毫秒） |
| `created_at` | 决策时间 |

### 7.2 实时决策徽章

团队群聊在流式响应中通过 SSE `decision` 事件下发本轮决策，气泡区顶部展示：标签、置信度、决策层级、命中关键词、耗时。

### 7.3 决策面板

侧边栏「决策内核」页面（`/decision`）展示：

- 本地模型加载状态；
- 三层链路 vs 规则基线的准确率 / 宏 F1 对比；
- 平均单条耗时；
- 最近决策记录明细表（标签、置信度、层级、关键词、耗时、诉求、时间）。

## 8. 接口一览

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/v1/decision/overview` | 模型状态 + 离线评测指标 + 最近决策日志（需登录） |

模块内部入口：

- `app.decision.router.predict(text)`：在线三层推理，返回 `label / confidence / layer / keyword / artifact / elapsed_ms`；
- `app.decision.train.train_and_save()`：训练并落盘模型；
- `app.decision.evaluate.evaluate()`：离线对比评测。

## 9. 降级与离线预案

| 异常情形 | 行为 |
| --- | --- |
| 模型文件不存在 | 直接走规则层，链路不中断 |
| 模型文件损坏 / 反序列化失败 | 静默降级规则层 |
| 单条推理抛异常 | 该条降级规则层 |
| 现场无外网 | 权重本地打包，推理不依赖外网；仅上游大模型回复需要联网 |
| 样本不足 | 退化为增强规则，并保留「分层决策 + 可插拔模型接口」的架构价值 |

## 10. 接入范围与后续扩展
